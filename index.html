Firebase Firestore セッティング方法:

  1. Firebase Console にログインし、プロジェクトを作成します。
  2. 「ウェブアプリを追加」を選択し、表示された `firebaseConfig` オブジェクトの値を上記に入力します。
  3. Firestore Database を作成（「テストモード」で開始可能）します。
  4. Firebase Rules を以下のように設定してください:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
